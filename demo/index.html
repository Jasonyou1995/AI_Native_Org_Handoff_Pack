先连接网关

先连接，然后检查已启动的 Ollama（11434）或 OpenAI 兼容服务（1234）。不会安装、下载或调用模型。

只检查网关所在环境的两个固定本机端口，不扫描你的局域网。

    以下仅生成配置，不会立即切换正在运行的网关。将这些值写入本地 .env；宿主进程需用 node --env-file=.env dist/src/server.js 重启，Docker Compose 需重新创建容器。普通 npm start 不会自动读取 .env。也可退出后重新运行个人启动器并选择模型。

    没有找到？Docker、模型和云端设置
    检测发生在运行网关的机器或容器内，不是在你的浏览器设备上。Docker 内的 127.0.0.1 是容器自己；宿主机上的 Ollama 需要另外配置可信地址与 LOCAL_ALLOWED_HOSTS。未找到不代表电脑上没有模型。
    无需模型也能运行明确标记的合成演示。真实推理需要你先启动本地服务并准备模型权重。本页不读取系统文件、不保存模型选择，也不接收云端密钥。
    OpenAI / DeepSeek 等云端连接由本地环境变量配置。只有公开声明、混合路径、策略允许及精确载荷批准都满足才会发送。未知和机密内容保持本地；本地失败不回退云端。
    

    连接后即可开始。请先使用虚构示例，不要用真实私密数据测试。
