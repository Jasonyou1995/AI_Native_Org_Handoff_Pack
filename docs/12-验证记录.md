## 性能口径

同一台开发机器、Node 24.22.1、100 次约 5,500 字节合成文本扫描：Rust 一次性子进程路径观测到 p50 约 25.7 ms、p95 约 39.7 ms，包含进程启动；显式 TypeScript 参考路径约 1.1 ms 和 3.2 ms。两组不是并发基准，不能外推客户硬件或模型延迟。选择 Rust 是为了有界的核心处理与线性正则，不是因为本次子进程实现更快。优化前应先用 `make bench` 重新测量。
