# 06 · 分工与里程碑

> 三个人，三条赛道，互不重叠。每周五 Demo Day，必须 demo 一个能跑的东西，不许只念进度。

## 一、三人分工

| 赛道 | 负责人 | 独占目录 | 交付物 |
|---|---|---|---|
| **A 工程** | 人 1 | `src/`、`tests/`、`demo/`、Docker 与 CI、`spec/MSG-DESIGN-SPEC.md` | 三臂编解码器、成本计量、门禁全绿 |
| **B 实验** | 人 2 | `bench/`、`analysis/`、`bench/prereg/`、`spec/COORDINATION-COST-SPEC.md`、`spec/ORG-TOPOLOGY-SPEC.md` | 组织模拟器、任务族、主网格、预注册 |
| **C 分析论文** | 人 3 | `~/Documents/GitHub/_private/handoff-paper/`、`leaderboard/`、`docs/04`、`docs/05` | 论文、投稿、榜单 |

**目录独占规则**：一个目录只有一个 owner。别人要改，走 PR，不直接改。这条规则比任何流程文档都有效。

**`spec/` 的例外要写清楚**：`spec/` 不是一个目录一个 owner，而是**按文件拆**。A 拥有 `MSG-DESIGN-SPEC.md`（库要实现的东西），B 拥有 `COORDINATION-COST-SPEC.md` 与 `ORG-TOPOLOGY-SPEC.md`（实验侧要测的东西）。按赛道拆比整目录给一个人更合理，因为改成本定义的人和跑实验的人是同一批人。**但每份 spec 仍然只有一个 owner**，其余两份改合同要全员签字。

**本地工具不进这张表**。开发时用的个人工具与技能属于每个人的本地环境，登记在被 gitignore 的个人文档里，**不进仓库、不进 README、不进本文件**。理由有两条：一是它们是每个人的选择，写进公共文档等于替别人做决定；二是公开列出本地装了什么，等于给供应链攻击者一份现成的目标清单。

### 两人降级方案

若只有 2 人，C 的分析部分并入 B，论文由 A 和 B 轮流执笔，A 负责工程与实验，B 负责统计与论文。代价：P4 阶段从 7 周压到 9 周，且 A 在 P3 结束后负载偏轻，需要主动把 P4 的图表与工件活揽过来。

```
P0 ──┬─ 0.5 三臂规范 ──┬── P1 工程 ──┬── P2 模拟器 ──┬── P3 主实验 ──┬── P4 论文 ──┐
     │                 │            │              │              │           │
     └─ 0.6 成本规格 ──┘            │              │              └─ 4.7 榜单  │
                                   │              │                             │
     └─ 0.8 文档 ────────────────── 2.8 README ────┴─ 4.1 统计 ──── 5.1 投稿 ───┘
```

**关键路径**：`0.5 → P1 → P2 → 3.4 预注册 → 3.5 主网格 → 4.1 统计 → 4.4 论文 → 4.6 预印本`。

**最早可并行点**：P0 结束当天，C 就可以开始写论文的引言和理论部分，因为理论框架不等实验。**不要等数据出来再想理论**，那是审稿人最爱抓的地方。

**最危险的串联点**：3.4 预注册必须在 3.5 主网格之前。任何为了"跑得好看"而推迟预注册的念头，都要被 Demo Day 当众拦下。

## 五、冲突解决规则

| 情况 | 规则 |
|---|---|
| 两人要改同一文件 | 找 owner，owner 给或不给，不给就换方案，不许绕过 |
| 有人在 main 直推 | CI 红则禁止合并。重写历史要问 Jason |
| 实验数据归谁 | 归赛道 B，C 只读。论文引用要注明 run id |
| 数据与图表不一致 | 以 `numbers_manifest.json` 为唯一事实来源 |
| 想改 spec | 停，问 Jason。spec 是合同，改合同要所有人签字 |
| 阻塞超过两天 | 升级到周一的同步会，不许闷头绕路 |

## 六、Fun 机制

| 机制 | 玩法 | 为什么有效 |
|---|---|---|
| **CCI 榜单** | 协同成本压成一个标量指标，做公开榜单，社区提交自己的交接协议排名 | 别人来提交就带来 star 和 issue，榜单本身就是产品 |
