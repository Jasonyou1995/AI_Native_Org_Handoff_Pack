# Personal quick start · 个人快速开始

**One person, one task, local first.** You do not need an enterprise account or a cloud key to try the gateway. Start with synthetic text, then connect a local model you already run. This is a pilot text gateway, not a general autonomous agent or a complete privacy detector.

**一个人，一个任务，本地优先。** 试用不需要企业账户或云端密钥。先用虚构文本，再接入已经运行的本地模型；当前是试点文本网关，不是通用自主智能体或完整隐私检测系统。

## One minute overview · 一分钟路线

1. Start the gateway and open the localhost address it prints. Enter its gateway token in the browser. That token is not an OpenAI/DeepSeek API key.
2. Choose **Try demo** to fill a synthetic task, then **Inspect** and **Run locally**. A synthetic result is explicitly marked and is not AI inference.
3. For real local inference, run the personal launcher beside your existing Ollama/compatible service, choose a detected model, and submit another synthetic task. Keep unknown/private input local. Cloud is optional and always separately approved.

1. 启动网关，打开输出的本机网址，在浏览器输入网关令牌；它不是模型 API Key。
2. 点击“试一个虚构任务”，再“检测”与“在本地处理”。合成输出明确标记，不冒充模型回答。
3. 真实推理时，在已有 Ollama/兼容服务旁运行个人启动器并选择模型，再试虚构任务；未知和私密内容留在本地，云端是另行批准的可选路径。

## A. Prepared Docker image · 已准备好的 Docker 镜像

For the packaged Linux AMD64 pilot, follow [offline release installation](14-离线安装与发布.md). It provides checksums, image identity and exact load/run commands. Docker and a browser must already be installed. The image contains the gateway and Rust scanner, not model weights. Other platforms need a compatible source build and their own acceptance test.

已打包的 Linux AMD64 试点镜像按[离线发布安装](14-离线安装与发布.md)操作，包含摘要、镜像标识与完整命令。需预装 Docker 与浏览器，镜像不含模型权重；其他平台需兼容源码构建并单独验收。

**Docker's localhost is the container itself.** Automatic discovery inside the container cannot see a model listening only on the host's localhost. Do not disable host security or expose Ollama publicly to make discovery work. Use the host launcher below, or deliberately configure an approved container/host address and `LOCAL_ALLOWED_HOSTS` using the [configuration guide](07-本地隐私网关.md).

**容器的 localhost 指容器自己。** 容器内自动检测无法看到仅监听宿主 localhost 的模型。不要为了检测关闭安全机制或把 Ollama 暴露到公网。可用下面的宿主启动器，或按[配置指南](07-本地隐私网关.md)配置受控宿主/容器地址与白名单。

## B. Host launcher beside your local model · 本机个人启动器

For a developer machine with Node.js 24, npm and Rust/Cargo already installed, from a reviewed source checkout:

适用于已安装 Node.js 24、npm、Rust/Cargo 的开发机器，在已审查的源码目录执行：

```bash
npm ci --ignore-scripts
npm run rust:build
npm run build
npm run personal
```

Dependency installation/build needs network access or preloaded caches. The launcher does not install model software, download weights, collect keys or save configuration. It generates a fresh process-only gateway token, listens on `127.0.0.1`, and disables cloud access. Choose a detected local model or the synthetic option. To deliberately start only the demo:

依赖安装/构建需要网络或预置缓存。启动器不安装模型软件、不下载权重、不收集密钥、不保存配置；它生成本次进程使用的随机令牌，仅监听 `127.0.0.1`，并关闭云端。选择检测到的本地模型，或选合成演示。仅运行演示可用：

```bash
npm run personal -- --demo
```

Keep the terminal open. Copy the printed gateway token only into your local gateway page. Stop with Ctrl+C; restart generates a new token and invalidates old requests. Do not share the terminal screenshot with its token. The browser keeps the token only in memory; reloading requires reconnecting.

保持终端开启，只把输出的网关令牌输入自己的本机页面。Ctrl+C 停止后重启会生成新令牌，旧请求失效；不要分享含令牌的终端截图。浏览器令牌仅留在内存，刷新需要重新连接。

### What detection means · 检测的含义

Authenticated discovery checks only two fixed endpoints from the gateway's own environment: Ollama at `127.0.0.1:11434/api/tags`, and an OpenAI-compatible model list at `127.0.0.1:1234/v1/models`. It does not scan the LAN, send a prompt, test model quality or automatically select an expensive model. Empty/unreachable services remain clearly unavailable. Other ports/authenticated model catalogs require deliberate manual configuration.

授权后的检测只访问网关环境的两个固定本机接口，不扫描内网、不发送提示、不测试模型质量、不自动选择高成本模型。服务为空或不可达会明确提示；其他端口及需认证的模型目录应手动配置。

A local HTTP address is not proof of local inference. Verify that the selected service/model does not proxy requests to a cloud. Prepare weights in advance and test with external egress disabled before using private input. Known cloud-marked discovery entries are excluded; that is not a universal proxy detector.

本地 HTTP 地址不证明推理发生在本地。确认服务与模型不把请求代理到云端；提前准备权重，禁止外网后用合成数据验证，再使用私密输入。检测会排除已识别的云端标记，但这不是通用代理检测器。

The browser's detected model menu **only generates configuration**, never changes the running provider. For a manual host configuration, put its safe `LOCAL_URL` and `LOCAL_MODEL` lines into `.env`, keep `CLOUD_ENABLED=false`, then stop and restart using:

浏览器模型菜单**只生成配置**，不改变运行中的提供方。手动宿主配置时，将生成的安全地址/模型写入 `.env`，保持云端关闭，然后停止并按以下命令重启：

```bash
node --env-file=.env dist/src/server.js
```

Plain `npm start` does not load `.env`. Docker Compose reads the project's `.env` configuration, but an existing container must be recreated to apply it. The personal launcher intentionally uses its own ephemeral choices, not a persistent cloud configuration.

普通 `npm start` 不读取 `.env`。Docker Compose 读取项目 `.env`，但旧容器需重新创建才能生效。个人启动器使用临时选择，不加载持久云配置。

## C. Optional cloud handoff · 可选云端交接

Use this only after local-only usage works and you have reviewed the provider's account terms, billing, data handling and permitted region. API credentials belong in the local server environment, never in browser fields, source code, screenshots or issues. This optional path requires Internet access. The personal launcher keeps it disabled; use the explicit server configuration workflow instead.

先跑通本地流程，再审查提供方账户条款、计费、数据处理与地域限制。API 凭据只放在本地服务环境，不填入浏览器、不提交仓库或截图。此路径需要互联网；个人启动器始终关闭云端，需按服务配置流程显式启用。

Choose one compatible text Chat Completions provider and a model your account supports:

| Provider | `CLOUD_URL` | `CLOUD_MODEL` |
|---|---|---|
| OpenAI | `https://api.openai.com/v1/chat/completions` | Your supported text Chat Completions model |
| DeepSeek | `https://api.deepseek.com/chat/completions` | Your supported model from its current model documentation |

Set `CLOUD_API_KEY` locally and `CLOUD_ENABLED=true`, then restart the configured gateway. Exact model capabilities and billing change; the adapter does not support every provider-specific parameter, streaming, tools or multimodal API. Start with a small public synthetic prompt. An incompatible response fails; it does not silently switch providers.

在本地设置 `CLOUD_API_KEY` 与 `CLOUD_ENABLED=true` 后重启。模型能力与计费会变化；适配器不支持所有专有参数、流式、工具或多模态 API。先用少量公开虚构提示验证；不兼容时明确失败，不自动换供应商。

The gateway only offers cloud approval when you choose public data and hybrid mode and all policy checks allow it. Read the full destination/model/payload preview before approval. Unknown or confidential content stays local. A failed local call never falls back to cloud. Detection can miss private details, so do not label private input public just to obtain a cloud answer.

仅在公开分类、混合模式及策略检查全部允许时，网关才提供云批准。批准前审阅完整目的地、模型与载荷；未知/机密保持本地，本地失败不回退云端。检测可能遗漏私密内容，不要为了获得云端答案把私密输入改为公开。

## Troubleshooting · 常见问题

- **Synthetic output:** no real model was selected/configured. Choose a model with the host launcher or apply local configuration and restart.
- **No model found:** start your existing service; check the gateway's container/host boundary. Detection does not install a model.
- **Discovery denied:** configure a gateway token and connect with it. Token-free loopback demo does not authorize discovery.
- **Rust unavailable:** build the Rust core or use the packaged image. The default scanner fails closed; do not hide a failed scanner by changing security settings.
- **Slow local answer:** the gateway currently has bounded provider timeouts; cold or oversized models may fail. Warm the model locally and select a hardware-appropriate model, not a cloud fallback.
- **Expired preview:** inspect again. Approvals expire after 120 seconds and are single-use.
